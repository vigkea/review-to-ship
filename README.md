# Review to Ship

一个把第一性原理和对抗式审查合并起来的 AI Skill。

它解决的不是如何提出更多问题，而是：

> 找到真正会影响结果的问题，修完必要部分，然后开始执行。

## 它适合什么时候用

- 你担心 AI 只是顺着你的方案表示同意
- 审查意见越来越多，已经分不清哪些必须修
- 你在陌生领域，无法判断 AI 说得是否真的对
- 你想知道一个计划、产品、自动化或内容能不能开始执行
- 你想从反复讨论切换到可验证的最小行动

也可以直接说：

```text
用 review-to-ship 审查这个方案，先判断我对这个领域是熟悉、半懂还是陌生，
再用第一性原理重建目标，做一次有边界的对抗式审查，只保留必要修改，
验证核心路径后直接开始执行。
```

## 工作流程

```text
校准领域认知
    ↓
第一性原理重建目标
    ↓
一次有边界的对抗式审查
    ↓
区分阻塞项、现在修、延后和拒绝
    ↓
做最小充分修改
    ↓
用正确的外部证据验证
    ↓
达到阈值就停止审查并交付
```

## 核心原则

1. AI 的详细和自信不是证据。
2. 陌生领域里，最危险的不是不知道，而是不知道自己无法验证。
3. 每个批评都必须对应具体失败场景、触发条件和证据。
4. 没有场景或证据的意见只能算假设，不能自动变成待办事项。
5. 目标不是消灭所有风险，而是让核心路径在可接受风险下跑通。
